@citation-js/plugin-bibtex 0.9.0 and @citation-js/plugin-ris 0.9.0 (MIT).
Their local parser dependencies @citation-js/date 0.5.1 and
@citation-js/name 0.4.2 are MIT; moo 0.5.3 is BSD-3-Clause;
sync-fetch-undici 0.7.1 and whatwg-mimetype 5.0.0 are MIT. Complete
available license texts and package notices are in dependencies/. The
application only invokes local bibliography parsers; DOI and URL strings
are never passed to a resolver.

Local PDF inspection uses PDF.js (pdfjs-dist 6.3.289), licensed Apache-2.0.
Its bundled worker, CMaps, ICC profile, standard fonts and WASM resources
ship with the upstream and third-party notices listed in dependencies/.
These assets are used locally for inert page rendering and text extraction;
they do not authorize PDF content uploads or online font loading.

Direct installer updates use electron-updater 6.6.2 and parse locally bundled
update configuration with js-yaml 4.3.2 (both MIT). Their license texts are in
dependencies/. Update checks use a configured release feed only after the
user chooses Check for updates; no manuscript or project metadata is sent.

The local interface uses @mantine/core and @mantine/hooks 9.6.3 (MIT),
with lucide-react 1.49.0 icons (ISC and retained Feather MIT notices).
Their complete distributed licenses and dependency notices are bundled in
dependencies/ and listed in dependencies/inventory.json. Floating UI and
the other UI dependencies run locally; no hosted fonts, icon service,
analytics, advertising, or component-gallery content is loaded by the app.
Source Serif 4's four existing Latin font faces also supply the renderer's
manuscript typography, with the same unmodified OFL assets listed above.
