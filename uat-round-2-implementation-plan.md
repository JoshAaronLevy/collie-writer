## Agreed UX behavior

- **Navigation and writing positions:** ordinary navigation between pages, including Return to work, starts at the top. Reopening a project, including on app startup, and switching Chapters/Sections retain the saved writing selection and scroll without taking keyboard focus automatically. Explicit passage links reveal their requested target.
- **Button backgrounds:** toolbar/navigation buttons and dropdown triggers are transparent at rest throughout the app. Primary actions such as Create, New chat, Send and confirmation actions retain their filled treatment. Hover, pressed, selected, unavailable and keyboard-focus states remain visible; opened menus, dialogs and tooltips remain opaque.
- **ChatGPT startup:** background preparation is silent and the connection dialog never opens automatically. The header opens Manage ChatGPT on demand. Actionable connection failures appear as a notice; an intentionally disconnected account produces neither an unsolicited dialog nor an error. Explicitly started sign-in retains progress and Cancel. Remove the obsolete automatic-prompt control from the dialog while leaving its previously saved preference record untouched.

## Implementation boundaries

- Retain `WorkspaceSessionProvider`, `useWorkspaceController`, the mounted `RichDraft` and existing draft registrations. Layout, notices and navigation presentation must not replace editor keys, document payloads or undo owners.
- Preserve current Save requests, exact retry identity, authoritative outcomes, native consent, cancellation boundaries and close/access protection. Removing routine UI must not clear work, imply completion, or hide required user choices.
- Keep automatic local protection and explicit project-file Save distinct. No storage, archive, database, IPC, credentials or AI operation-format change is needed for this plan.
- Preserve named keyboard-accessible controls, menu ref/event forwarding, dialog focus traps, composition guards, reduced motion, contrast and static CSP-compatible styling. No global removal of focus outlines.
- Use existing Tabler icons, `IconButton`, `ActionMenu`, theme tokens and layout owners. No new dependency, general navigation framework, generic notification system or new persistence subsystem is warranted.
- Keep the current review-options Submit unavailable. No AI review submission, account-provider redesign, cleanup feature or release work is included.
