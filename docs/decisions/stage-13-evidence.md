# Stage 13 — human evidence relationships

September 30, 2026. Research questions and claims are editable project records with optional section and note associations. A manual evidence link connects one source, optionally one exact excerpt, to one claim or section. Its role is support, challenge, background or potential use; its origin is human, with an explicit review flag. A link records the target revision when created or confirmed. Later edits to the target show a review warning instead of silently renewing the assessment. Archived or merged targets and older source versions remain visible. Section navigation uses the existing outline replacement mapping; an exact excerpt opens its retained inspected version and page. A section move alone does not invalidate its revision, while changed wording does.

Per-question source decisions are candidate, kept or rejected. Rejection requires a reason and is scoped to that question/source pair. A later candidate or kept decision reverses it; prior rows are kept as read-only revisions. Neither decisions nor manual links alter draft citations. Source-to-section uses come from the Stage 11 source library, while actual citation occurrences are projected from the current document AST and labeled separately. The same source may be linked to multiple sections and evidence targets; one logical source/excerpt/target/role combination has one record.

All mutations use an operation ID, project scope and expected revisions. Links and questions can be removed or archived reversibly; prior values are kept in revision records. Stage 13 adds no AI suggestions, graph display or citation insertion. The panel reads the local worker through narrow validated IPC. The view has finite entity bounds; larger projects will need pagination in a later stage. Source merges retain earlier IDs and version ownership; old relationships remain visible for human review. Archive/restore and native navigation remain user acceptance work.
