# Stage 14 — device-local search projection

September 30, 2026. Search uses the already required SQLite FTS5 runtime and a disposable `search.sqlite` sidecar inside each workspace. It is not part of `project.sqlite` or a `.collie` archive. Draft sections, independent notes, canonical source metadata, research questions/claims and saved text-bearing source pages remain the authoritative records. Search entries store their entity revision or page text hash, source/version/page or section/note identity, and filter IDs. Rebuilding clears only the sidecar projection. Archive restore or independent copy creates a fresh local index on first use.

Queries are literal FTS5 phrases: embedded double quotes are escaped and the whole phrase is bound as a parameter. Filters for type, note tag, linked section and source are deterministic, project-local entry fields. Results are paged in groups of 50 and rendered as text with literal highlighting; imported text is never injected as HTML. The worker compares each hit against the current canonical revision/state. Changed hits are labeled stale, removed/archived hits are labeled removed and cannot be opened; retained source-version pages are labeled older version and can be opened in the existing inspector. A hit opens its section, note, source, claim/question or inspected version/page. A draft hit currently opens its section rather than a precise text offset.

An index pass scans committed records in small worker batches, updating only changed entries and removing obsolete entries after a completed pass. It records a target project head and never treats unsaved renderer buffers as indexed. A head change schedules another pass; progress shows examined/total counts and the last indexed head. Cancel keeps partial derived entries, while interruption is surfaced on restart and requires a user retry. A failed/corrupt sidecar cannot block project opening; **Rebuild local index** retains its old files under a new local name before creating a fresh projection. Source inspection remains separate: saved text pages can be searched, while unextracted/scanned pages cannot. Activity shows text/no-text page counts and up to 100 active sources whose selected version is not fully indexed.

FTS5 `unicode61` folds case and common diacritics. It does not provide language-specific stemming, arbitrary substring search or dependable segmentation for languages without spaces. Whole-section indexing can take noticeable time for very large sections; responsiveness and timing remain user-owned observations, not claimed results. No network, embeddings, AI or automatic web discovery are involved.
