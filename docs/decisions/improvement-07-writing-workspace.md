# I07 — Focused writing workspace

October 2, 2026. **Implementation complete — awaiting user testing.** I07 changes the presentation of existing writing, outline and history operations. Source inspection does not establish runtime, native, accessibility or release acceptance.

## Layout and ownership

`WritingWorkspace` lives inside I03's retained Write region. A sidebar offers a labeled project switcher, Projects access, nested outline rows, container expansion and a first-section jump for chapters/parts. The manuscript has a paper surface and bounded reading measure. The optional companion has exactly one mode: `closed`, `notes`, `source` or `ai`. Project/file actions and history remain labeled destinations; Search, Research, Save and Export have direct entry points. The separate app Settings/Help navigation and citeproc attribution remain available outside focus mode; the required attribution remains visible in focus mode too.

The persistent session controller still owns the manuscript instance, revisions, retry requests, images, jobs, section details, close/access handshake and protection cadence. Pane changes only hide/inert existing regions. They do not change the manuscript key, reconstruct its document, reparent its host or clear undo. Actual project/section changes and structural history actions continue through I03's guarded transitions and may replace the editor after protection. Dialog draft registrations require Apply or explicit Cancel before navigation/close. Outline submission temporarily hands its intent to the existing structural-operation owner; failed forms retain input, and closing a failed form never clears an already dispatched retry.

The Notes companion reads saved note text. Source reads saved metadata and retained excerpts, including their kind, page label and active/earlier version indication, with at most 20 excerpts visible. Both link to the original retained Research editors/inspector using typed exact targets. They are read-only companions, not second editing owners or new content stores. Reads occur on opening/returning or explicit Refresh; stale async completions are ignored, and failed reads offer retry. AI shows an unavailable explanation with no composer, login, provider request or promise of enabled inference. Broader Research composition remains I08.

## Responsive and local presentation state

`collie.writing-view.v1` is a bounded, strictly read device-local preference: version, outline width (200–360 pixels), companion width (260–460 pixels), focus boolean and panel mode. Defaults are 248/320 pixels, focus off and panel closed. It contains no project identifiers, paths, manuscript, source content or credentials and never enters portable projects. Invalid values fall back to defaults; a failed preference write leaves the current layout usable with an explanatory status.

At widths of 78rem or less, the layout becomes alternate Manuscript / Projects and outline / companion views, each with a usable full-width content area. Hidden panes are inert and retained. Entering the narrow layout chooses the pane containing focus, so a resize does not deliberately hide an active composition. Manual view changes refuse active composition. Width handles support pointer capture, Left/Right arrows and Home/End, with labeled separator/value semantics. Focus mode hides side panes and app header/footer, retains urgent session status, and has a visible Exit focus mode action. Width, panel and focus choices persist locally; the narrow-view selection, selected companion record and expanded section-details state are session UI only.

## Tools, selection and existing data contracts

Common marks, Undo/Redo, Style, Insert and More tools replace the long toolbar. Table growth and image metadata appear only for the relevant selection. Find/replace and section details open on request. Outline actions retain drag plus Move up/down/to, create/details, split/merge, archive/trash/restore and merged-section replacement navigation. History retains checkpoint comparison, restore, reviewed retention cleanup and explicit anchor repair. These call the existing production commands and preserve their head/revision checks and structural checkpoints.

Link, image and citation forms use labeled Mantine dialogs. `selection.ts` captures the actual editor identity, immutable ProseMirror document and selection bookmark. Apply restores only against the same live, unchanged document, outside composition; otherwise it refuses and keeps the form. Menu actions capture before the menu changes focus. Dialog close returns focus after the overlay exits. Image insertion waits until the metadata dialog has exited, then uses the existing native picker, managed-asset import and exact retry operation. After asynchronous import it checks the captured document/selection and project/section again. A stale location leaves the asset retained rather than guessing an insertion point. Annotation capture similarly checks its exact passage after local protection before opening the existing annotations owner. Plain-text clipboard reads also refuse a stale target. Native editor actions do not act on a hidden editor or a focused dialog/form field.

Reference tools and footnote editor bodies stay mounted when their tools are collapsed. Citations retain ordered source items and locator/prefix/suffix data; author footnote bodies retain their existing synchronization and serialization. Table cells remain plain text. No new AST node, rich-text capability or output behavior is introduced.

## Status, styling and boundaries

A compact expandable status beside the project title distinguishes unprotected/protecting/protected local work from no destination, file progress, older selected file, saved selected file, unavailable, external conflict and interrupted file state. Normal success copy is inside the disclosure. `WorkspaceStatus` still shows errors, explicit draft blockers, structural retries, access changes, file jobs/conflicts, exports and close progress across all destinations, including focus mode. It never claims a cloud upload.

Workspace layout lives in its CSS Module; editor, reference, outline and history rules live beside their owners. The corresponding legacy rules were removed from `Projects.css`. Mantine components use the existing static theme and CSP strategy; only runtime pane widths/positioning use CSSOM values. No dependency or remote asset was added. Main/worker/IPC, persistent SQL/minimum reader **10**, editor AST **1**, archive container **1** and frozen compilation **3** are unchanged. No migration, recovery expiry, provider or export redesign is part of I07.

All keyboard, IME, selection, undo, pane sizing, native picker/save/close, packaged CSP, content-fidelity and screen-reader behavior awaits the [manual guide](../manual-testing/improvement-I07.md). Release remains **NO-GO**. Stop before I08 unless explicitly requested.
