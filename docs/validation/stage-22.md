## Implemented preparation

- `electron-builder.microsoft.cjs` is a native-Windows, production-only alias of the direct configuration. The selected Microsoft Store EXE listing reuses the exact retained, signed direct-production NSIS x64 artifact. Identity, working/profile paths, file association, updates and Paddle/direct purchase restore are shared; no Microsoft IAP or MSIX adapter is needed for this decision.
- `electron-builder.direct.cjs` explicitly marks its signed metadata as direct distribution and includes `.dll` as well as `.node` signing extensions. Installed builder 26.15.3 source includes EXEs by default and requires the additional extensions for these PE files. All actual certificate coverage remains pending owner evidence.
- `src/main/release.ts` rejects MAS and Windows Store packaged/MSIX runtimes before profile, storage, direct-purchase UI and updater initialization. An explicit unsupported packaged distribution is also refused. Legacy Stage 21 direct metadata remains readable. A Microsoft Store EXE download is the ordinary direct runtime and is unaffected by this refusal.
- `electron-builder.mas.cjs` deliberately refuses packaging with the native implementation reason. It is a closed channel entry point, **not a usable MAS configuration**. No environment variable bypass, fabricated provisioning, broad filesystem entitlement or replacement receipt verifier was added.
- `src/main/entitlements/grant.ts` and `service.ts` restrict desktop cache/import authority and issuer-availability reporting to direct grants. A future store key cannot implicitly enable cross-store restore. The shared capability policy, free designation and all-project reading/export/backup/recovery remain unchanged.
- [Microsoft owner instructions](../release/microsoft-exe.md), [listing/review drafts](../release/store-listings.md) and the [manual guide](../manual-testing/stage-22.md) describe exact-artifact reuse, silent installation, immutable hosting, payment/update disclosures, privacy, review resources and safe channel switching. The access and privacy contracts and project indexes are updated.
