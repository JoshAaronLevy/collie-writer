# UAT03 — Compact writing chrome and contextual outline actions

October 6, 2026. **Implementation complete — awaiting user testing.** Implements only UAT03 of the [UAT plan](../../uat-implementation-plan.md). Existing UAT01/UAT02 work was preserved. UAT04–UAT05 remain unstarted; release remains NO-GO.

## Implementation and source evidence

- Added exact `@tabler/icons-react` **3.49.0**, with its exact `@tabler/icons` **3.49.0** dependency. Read registry metadata, published package scripts and the [official React integration](https://docs.tabler.io/icons/libraries/react); use individual named SVG imports, no remote assets or registry abstraction. Inspected both packages' scripts before installation. Installation used `--ignore-scripts --no-audit --no-fund`; no package build/test hooks ran. The first install reported the shell's Node 22/npm 10 mismatch with the repository pins. Repeated installation and ran all checks with the existing repository-local Node **24.21.0** / npm **11.19.0**, without warnings. Unmodified MIT licenses are bundled under `resources/licenses/dependencies/`, with two inventory entries and an appended NOTICE attribution. Lucide remains for its other consumers and its notices remain intact.
- A narrow shared `IconButton` wraps the existing Mantine button and tooltip. It supplies an accessible name, 44 CSS-pixel default target, focus ring, semantic pressed/unavailable treatment, 1.5-second hover delay and immediate keyboard-focus descriptions. Unavailable icon actions are focusable via `aria-disabled`, and pointer/Enter/Space activation is refused. Existing reduced-motion/high-contrast tokens apply. Tooltip placement uses Mantine's existing CSSOM/portal path, with static semantic CSS and no CSP relaxation.
- RichDraft uses Bold/Italic/Underline/Strike and Undo/Redo glyphs with its original command functions, selection preservation, enabled/pressed conditions, IME checks and Note-mode restrictions. Style, Insert and More tools still contain their existing commands. The future wand is absent.
- Save has one joined visual boundary, a disk-plus-text primary and an independently named chevron. The primary reserves its width through Save/Saving/Retry Save. UAT01's scoped busy/outcome/retry owner, native first-Save picker, Save As/Backup/Locate/details eligibility and progress/recovery disclosures are unchanged.
- Write removes the standalone status line while retaining status in Details and keeping reading-only feedback. Search, focus mode and close-companion controls use icons. The sidebar loses its project switch/browse controls; the app header Projects route remains. Narrow labels name Outline. Semantic wrapping/spacing remains local to each feature.
- Each outline row now has a separate ellipsis outside its draggable title. Its commands close over that row's ID; opening a form stores an independent target snapshot, and missing targets never fall back to the active manuscript. Delayed actions cannot follow a later global row focus. The dialog identifies its target and keeps the existing explicit draft, synchronous submit, pending operation and Cancel behavior. Actions preserve move/details/split/merge/archive/trash/restore, Part first-writing navigation and merged-item replacement access. Split requires the currently open editable item; leaf-only merge restrictions remain. The redundant selected summary and bottom menu are removed. Row actions reserve space and remain visible on hover/focus/open/touch; reduced indentation keeps the eight-level outline usable without changing hierarchy.

Changed owners: `components/ui/{IconButton,ActionMenu}`, `editor/RichDraft.tsx`, `features/workspace/{WritingWorkspace,SaveMenu}` and scoped CSS, `features/outline/OutlinePanel` and CSS, package/lockfile and license records. No worker/main/preload, command, project/editor/history/archive/compilation, AI, Save or preference format changes were needed. Current SQL/minimum reader **14**, manuscript/history **2**, compilation **4**, AST/archive **1**, search projection **2** and device-local writing-position **1** remain unchanged.
