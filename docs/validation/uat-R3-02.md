## Changes and ownership

- `ChatMessage.tsx` supplies the shared presentation for imported messages, native prompts and native replies: right/left theme bubbles, accessible authorship, timestamp, conditional linked-Research icon and one source disclosure. Right-click, Shift+F10 and the context-menu key open Copy, native prompt reuse/sent context, and Sources where relevant. Copy uses canonical message text. Menu dismissal restores bubble focus; source disclosure moves focus to its content. Existing request, draft, reference-review, citation and navigation owners remain authoritative.
- `ConversationPanel.tsx` uses the shared bubbles and one visible-pane timestamp refresh, retains streaming/Stop and genuine failure/protection/recovery notices, and removes permanent message utility rows. The R3-01 paging/reading anchors and targeted navigation remain. `message-time.ts` formats native and known-zone imported times locally, preserves date-only precision and unknown-zone wall times, omits invalid/missing values, and never writes display dates or changes message order.
- `ChatMarkdown.tsx` replaces the regex subset with locally bundled `react-markdown` and `remark-gfm`, including heading hierarchy, nested lists/emphasis, quotes, fenced/inline code, rules, tables, task lists, strikethrough, autolinks and footnotes. Links use the existing main-process external-opening policy; footnote targets are unique per body. Raw HTML is skipped. Images have a short unavailable placeholder pending R3-03. `Conversations.module.css` owns the bubble, focus and local table/code overflow rules; replaced headings, tool rows, separators and duplicate source styles are removed.
- `markdown-provenance.ts` associates rendered leaves with canonical UTF-16 offsets using the same parser's token ranges. Escapes/entities map atomically; direct text supports partial selection. Inline/code line endings and table-code escaped pipes use explicit parser transformations. Ambiguous transformations remain readable but unanchored. `chat-selection.ts` requires a provable, ordered selection, excludes generated badges/placeholders/footnote controls, prevents split surrogate pairs, and returns the exact retained answer slice. Citation badges retain their original canonical passage in the tooltip and follow its enclosing textual block, as before. No substring guessing, stored-answer rewriting or receipt change is involved.
- `ResearchAnswer.tsx` combines web references, saved-source receipts, exact/possible Research matches and related project knowledge in the single disclosure. Only an exact active source produces the icon; unsaved web references remain available through Sources → Add to Research. Actual lookup failure exposes Retry, while ordinary pending reads stay quiet. Selection-triggered Save reference, retained cancellation/resumption and deliberate Cite remain with their existing owners. `ConversationKnowledge.tsx` loses the superseded `ConversationReferences` renderer.
- `useImportedLinks.ts` automatically reads only the mounted imported window, with at most three concurrent local reads and guards for project/workspace/head/message/revision. No project-wide index or persistent link cache is introduced. `ImportedMessageLinks.tsx` renders the same bubble and paged source disclosure; active links produce the icon, removed-only links do not. Existing worker alias resolution deduplicates merged destinations. `src/worker/projects/conversations.ts` orders active imported sources and exact native matches ahead of removed/possible results before the existing result limits, so those limits do not hide the first genuine linked source.
