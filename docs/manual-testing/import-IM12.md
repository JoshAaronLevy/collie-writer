## Setup and normal workflow

Use a new disposable project and disposable input/project copies. Launch the updated app using your normal development workflow (`npm run dev`, if that is your usual workflow); these launch steps are for you only. Create/open the project before using Import. If the environment or your ChatGPT account cannot run a scenario, record it as unverified. Do not manufacture failures or edit protected storage.

1. **Open Import from Write, Research or project actions.** Expect the same project-scoped dialog, named destination, Select files, independent AI chats / Sources & research / Notes choices and optional instructions. This does not create a project or contact ChatGPT.
2. **Select copies from all six folders listed below, repeating Add files.** Expect one accumulated selection, 17 retained originals for the documented snapshot, sizes and per-file intake outcomes. Removing a checkbox or discarding a selection retains its original bytes, including private/excluded content. Native picker cancellation leaves existing choices intact.
3. **Choose AI chats and Sources & research; leave Notes unchecked. Click Inspect selected files locally.** Expect file/record coverage, identities, variants, source occurrences, exclusions and exact paged text. Review the complete matrix below. Inventory is not accepted project content or ChatGPT analysis. A notes-only pass requires an actual supported text/Markdown or structured note input; chat prose must not become an invented note.
4. **Open Review analysis plan / progress.** Expect intake to exit before the separate progress dialog opens. Choose your own connected ChatGPT account/model through the existing Manage ChatGPT route when necessary. Review remaining analysis, the finite request ceiling and disclosed packet content; only explicit Analyze authorized parts starts requests. No manuscript, existing Research or unrelated chat context is sent for import analysis. Counts distinguish fragments, parts and eventual imported items.
5. **Dismiss progress during a run, then reopen Import → Review analysis plan / progress.** Expect saved progress and Stop to remain discoverable; dismissal does not cancel or send again. Stop preserves completed results. Explicitly review remaining work to authorize only never-attempted parts; failed/invalid/uncertain parts require separately reviewed reanalysis. Completion never force-opens a dialog or adds domain records.
6. **Open Review proposed import.** Inspect Chats, Sources, Notes and Issues. Choose original representations, correct supported titles/source fields, resolve duplicates and choose new versus existing Research sources. AI titles remain suggestions; original text/order/roles and source grades are evidence of the export, not verified facts. Include a chat and its eligible unambiguous messages using the explicit grouped action, or decide individual records. Resolve or explicitly exclude incomplete/conflicted records. Review any partial-exclusion summary before proceeding.
7. **Prepare final confirmation, inspect counts/destinations, then dismiss.** Expect no ordinary Chats/Research/Notes additions yet. Reopening retains protected choices. Confirm import must remain an explicit action after successful analysis and local preparation; typing or IME composition must not confirm it.
8. **Confirm import once.** Expect the Import report with the accepted counts and immutable receipt; analysis details are collapsed. Only approved destinations are added. Existing writing, retained forms and undo remain intact. Import completion protects local work; use Save separately to write the `.collie` file. Reopen Import, choose the completed saved selection and View import report: expect the same report without another request or acceptance. Use New selection for further material.
9. **Open a report's source/note in Research.** Expect the dialog to fully exit before navigation. New metadata stays unverified; a reused source keeps its existing metadata and verification. Read Imported origins, then open an available exact originating message. Excluded chats/messages leave retained input provenance without a fabricated visible conversation or source excerpt.
10. **Open an imported chat in ordinary history.** Use Read / Find original history, then Read transcript and Find. Expect ordered originals with historical roles/times and separately labeled later Collie turns. Long text has explicit slices and continuation. Send a follow-up explicitly: expect a normal retained reply and bounded, disclosed imported background context. Inspect Context / Memory and source links; imported prose is not an instruction or verified research. Archived chats and do-not-recall intent must retain their documented exclusions.
11. **Cite an imported Research source through the ordinary citation flow.** Expect the source review and explicit Apply citation at the captured manuscript selection. Import itself must not insert writing or citations. Export chats/bibliography/writing: supported text/order/metadata should survive, with omissions disclosed rather than implied full provenance fidelity.
12. **Save, close/reopen, Backup/Restore and make an independent project copy through normal UI.** Expect pending reviews, accepted content, originals and reports to survive without the reference repository. Stage external disposable copies and move those copies elsewhere before local review/confirmation: protected originals should suffice. Reopening/copying must not restart provider work. Import-bearing working-copy removal is deliberately refused; storage maintenance must not delete these originals or recovery.
13. **Repeat the same input and vary categories on separate disposable selections/projects.** Expect equivalent identities to consolidate and exact accepted items to default to Skip; changed content under existing IDs requires review, without overwriting or splicing into later replies. Unchecked destination categories stay unchanged. Change relevant project/source data after preparing a preview: expect renewed local review/confirmation for stale targets, with no automatic reanalysis.
14. **Exercise keyboard, narrow-window and zoom use.** Expect reachable wrapping actions, bounded lists/text, focus containment, safe dialog exit and return to the surviving Import entry. Navigate or focus elsewhere during a transition: it must not steal focus. Dismiss/reopen a naturally encountered uncertain analysis/commit outcome: Import and saved-outcome recovery should remain reachable; checks do not resend inference. Record real provider/local failures and use the indicated recovery action, without creating artificial failures.
