## Available now: capture and local review history

1. From this repository, with the existing pinned dependencies already installed, run `npm run dev` yourself. Open a disposable project that has editing access (designate the free project through the normal access screen if necessary). Expected: the existing local writing flow remains available; no AI login or request starts automatically.
2. Write a short paragraph such as “These paragraphs is a draft.” Add a heading, a list and a short bold phrase using ordinary editor controls. Open the AI writing companion and select **Proofreading**. Expected: one calm mechanics-review surface appears alongside the retained manuscript, with no extra workspace column or invented results.
3. Select a short passage in the manuscript, then choose **Review selected passage**. Expected: pending writing is protected locally; the exact included text, text-run count, source section and coverage appear before any request. The section selection stays tied to this captured revision.
4. Expand **Included text** and **Exact instructions and request context**. Expected: only the declared supported text is listed; no other section, research source, project description or conversation is attached. The language is en-US. No prose is modified.
5. Choose **Clear capture**, then **Review current section**. On a disposable section containing an image, table, block quotation, citation or author footnote, inspect coverage. Expected: applicable unsupported content is listed as excluded; reference atoms, table text and footnote bodies are not eligible replacements. Different marks split text runs. A selection containing an image asks for a narrower passage. An empty/unsupported-only scope is refused with writing retained.
6. Inspect the provider explanation. Expected with the current checkout: actual unavailable/configuration/eligibility reasons, no fabricated model or account success, and **Run reviewed request** unavailable. **Save review locally** remains available for an editable project. Nothing is queued for later provider activation.
7. Save the review locally and reopen it from **Saved reviews**. Expected: its original scope/coverage is retained and its outcome says **Saved locally · not sent**. There are no findings or assistant response. Create another local review and switch between them; review history remains distinct from conversation history.
8. Prepare another capture without saving. Switch the AI selector to Conversations, close/reopen the companion, and visit another workspace destination. Expected: the capture remains and the global notice returns to Proofreading. A normal project replacement/close asks you to save or clear the capture. Clearing it keeps saved reviews and all manuscript text.
9. Prepare a capture, then change its manuscript text before saving the review. Expected: the app asks you to choose/review the scope again instead of silently updating or sending the old capture. Oversize scopes ask for a smaller selection; no hidden truncation or batching occurs.
10. Save the disposable project through the normal native picker, close/reopen it, and inspect saved reviews. Make a Backup and an independent Duplicate/Restore copy through existing project actions. Expected: acknowledged reviews travel with the project; copies have their own project identity and no account/execution authority. The original file and backup are retained. For an older-format project, use a disposable copy; opening upgrades locally through retained migration copies, never by overwriting the selected archive in place.
11. Export the manuscript with the existing export flow. Expected: its writing and existing references are exported; prompts, coverage, findings and review commentary are excluded. Project Save/Backup contains review history, while manuscript output remains separate. Existing native/export fidelity gates remain pending.
12. Using keyboard navigation, narrow window/200% zoom, selected appearance/high contrast/reduced motion and VoiceOver/NVDA where available, revisit the selector, coverage disclosures, saved-review paging and return notice. Expected: named controls, visible focus, readable text and retained selection/scroll; hidden panels are not keyboard destinations. Record any actual focus or layout problem.
