# Stage 18 manual acceptance guide

Use your normal local launch workflow and disposable copies of projects. The assistant has not launched the app or run any checks. Projects already created in Stage 17 remain stored; the new free policy requires an explicit editing designation. No real issuer key or grant is available in this checkout. Do not generate synthetic keys/grants, edit access files, change your system clock, use a hidden paid toggle or run automated suites for this guide.

Stage 18 complete. As a user:

1. When I launch Collie Writer and open Access and editable project, I should see untimed free access, no trial countdown/ads, the offline policy and a truthful message that paid activation is not configured. Reading my projects should require no account.
2. When I open a disposable project and choose **Use this project for free editing**, I should be able to edit writing, notes, sources, evidence, citations and outline items. After protecting edits and restarting normally, this project should remain designated.
3. When I open or create a second project, it should initially allow reading and individual exports. Choosing it for free editing should make it editable while leaving the previous project's content intact. Reopening the previous project should allow browsing its sections, notes, source originals, history and search; mutation controls should be unavailable until I explicitly switch designation back.
4. When I leave a note or source draft pending and switch projects, the app should protect it before switching. A pending question/claim/decision/transcription should keep the project open with an actionable save/clear message. After I save that draft, switching should work and its content should still be there when I return.
5. When I export each of DOCX, PDF, Markdown, plain text and bibliography from a non-designated project, full supported content should remain available without a watermark. Existing fidelity gates still apply. When I back up and restore a disposable project, the restored copy should be readable before any designation choice and should not inherit editing designation.
6. If I already saved recipes during Stage 17, loading one should restore its selection/order/preset and let me export one format at a time. Creating/updating recipes and selecting multiple simultaneous output formats should be unavailable in free mode. If I have no existing recipe, leave this scenario pending rather than creating testing-only license material.
7. When I inspect the edition/offline explanation, I should see the intended USD monthly/lifetime prices, identical edition capabilities, unlimited paid editable projects, all future nonfiction edition updates for lifetime, and signed subscription grace of up to 14 days. No purchase or automatic conversion should start.

Paid activation, authentic signature/replay rejection, subscription expiry/grace/clock handling, signed revocation, lifetime updates and loss with an in-flight draft remain **unverified and unavailable for demonstration until authentic issuer configuration exists**. Once legitimate access documents are available through the implemented product path, the user should confirm that only authentic newer decisions affect paid capabilities, revoked/expired states retain essential access, pending drafts survive, and the same transitioning project can be explicitly retained for free editing. Do not infer these outcomes from source inspection.
