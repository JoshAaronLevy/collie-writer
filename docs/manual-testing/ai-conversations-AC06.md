1. Save and close the currently running development app normally, stop its old development process, then run `npm run dev` and open the disposable project. Expected: existing writing/chats remain readable and Save/close work with the updated worker. Do not use a mixed old/new Electron session to assess the migration.
2. Open AI → New chat. Expected: compact Project context and Search the web controls above the composer; search starts off. Connect your ChatGPT account and choose a model if needed. Merely opening the pane or turning search on sends nothing.
3. With search off, send a short project question. Expected: an ordinary streaming answer and follow-up chat still work. View sent context to inspect the retained snapshot.
4. Turn Search the web on. Expected: its selected state is visible and a short line explains that shared context may inform search queries. Ask a public factual question and explicitly request supporting sources. Expected, if the account/model permits search: streaming text, successful finalization, clickable numbered citations and Sources by the answer. A refusal is an actual unmet live-search result, not acceptance of this stage; use View error details and report the sanitized log.
5. Open a citation/reference. Expected: the normal external-link confirmation, then the correct public page if you proceed. Inspect cited claims against the page. Ask for a response with headings, lists, emphasis and a non-BMP character such as an emoji; expected citation badges remain with the appropriate paragraph/list item and tooltips identify the cited passage. Other pages retrieved, when supplied, appear in a collapsed disclosure. Missing/invalid source details produce a warning while retaining useful answer text.
6. Ask a web question about the existing saved source, supplying its exact URL, and request that page as a citation. Expected if returned: In Research and Open source point to the existing record; no duplicate source is created. Title-only candidates say Possible existing source / Review match. On a disposable project, a returned removed source remains labeled removed; it is not restored.
7. Save the project, close/reopen it and reopen the researched conversation. Expected: answer, citation links, reference list and source warnings survive without a network resend. Export the transcript from the chat menu; expected public reference metadata/URLs accompany the text. Open a copy of the saved project through the normal file picker; expected references belong to that copied project and existing Research links resolve there.
8. Send another search request and use Stop during streaming. Expected: any protected partial text remains and the outcome stays stopped/interrupted when completion cannot be confirmed. It does not claim to have completed research or to have refunded usage. Closing or reopening does not resume the search.
9. If a search request is naturally refused, use Try without web search with an empty composer. Expected: the original prompt becomes an editable draft, search is off, and nothing sends until you press Send. Existing text chat stays available for search-specific refusals; genuine account/usage failures still require their stated action. If you already have a draft, it is not overwritten. Change model or context and explicitly send again as desired.
10. Check narrow panes, keyboard navigation, zoom and scrolling while an answer streams. Expected: controls wrap, Send/Stop remain reachable, Enter/Shift+Enter and composition behavior remain, focus is not stolen, and citations have readable names. Search is off after an app restart; saved research results remain intact.
