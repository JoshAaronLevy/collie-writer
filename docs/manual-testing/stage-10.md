# Stage 10 manual acceptance guide

Stage 10 complete. As a user:

1. Open Collie Writer with a disposable local project while offline, choose **Quick capture note**, enter a title and text, and protect it locally. The note appears in Inbox without signing in or using AI; after closing and reopening, its text remains.
2. Link the note to two sections, open each linked section from the note, and move one section in the outline. The note keeps both links and navigation reaches the moved section.
3. Create a tag and category, apply them to the note, filter by each, rename one and remove it. The note remains intact. Merge a duplicate label into the one you want to keep; the note retains the surviving membership.
4. Move a note to trash, show Trash, and restore it. Its content and section links return. Archive a note and find it in Archived.
5. Select text within one manuscript paragraph, choose **Annotate selection**, add an interpretation, and save it. The exact quote stays separate from editable interpretation. Add text before the quote and confirm it remains linked; remove the quoted text and confirm the comment displays an orphaned state while preserving quote and interpretation.
   Before saving a separate annotation draft, try switching projects or closing; the app should keep the window on the visible draft and ask you to save it first.
6. Begin editing a note, switch projects or close the app, and reopen the original project. The note edit should be protected locally before the transition; if storage cannot protect it, the transition should stop with the visible draft available to copy.
7. With disposable copies, Save or Backup the project and Restore or Duplicate it. Notes, labels, links and comments should travel with the portable project; local protection and the chosen-file save should show separate status.

Please report any mismatch, including platform and the action that led to it. These are user actions; no automated suite or assistant-run checks are part of this guide.
