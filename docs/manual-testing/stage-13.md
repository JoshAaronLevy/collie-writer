# Stage 13 manual acceptance guide

Stage 13 complete. As a user:

1. Open a disposable local project and create three text sections. Add one source and link it to all three sections in the source library. In **Questions, claims and evidence**, choose that source under **Source to sections and evidence**; all three section links should appear and each should open its section.
2. Create a research question and claim, optionally associating each with a section or note. Edit the text, archive and restore one; the current text/state and earlier revision should remain visible after reopening the project.
3. Inspect the source and save two exact excerpts. Create one **support** and one **challenge** link from them to the claim, then a manual link to a section. The panel should show both roles, quotes, human review status, original version and distinct section/claim targets. **Go to exact excerpt**, **Go to claim** and **Go to section** should reach the selected records by keyboard or pointer.
4. Create a second question. Mark the source kept for it, then reject the source for the first question with a reason. The kept decision and all source-library uses and actual citations should remain unchanged. Mark the first decision candidate or kept again; its prior rejected state should appear in history.
5. Insert a normal manuscript citation to that source using the existing citation control. The panel should count it as an **actual citation** separately from manual links and source-library uses. Follow **Go to citation** to its draft location.
6. Move a linked section in the outline, then edit its wording. The source and evidence links should still appear; changed target wording should call for review. Confirm against the current target explicitly. Reimport a changed source version and make it active; the old exact excerpt should remain available and show that it belongs to an older version.
7. Remove and restore a manual link, then save or back up the disposable project and reopen or restore a copy. Questions, claims, decisions, links, revision history and old excerpt provenance should remain; no draft citation should have been removed by a decision or link change.

Please report your platform and any mismatch. These actions have not been performed by the assistant.
