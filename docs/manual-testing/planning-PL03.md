# PL03 — Collection and passage walkthrough

**Implementation complete — awaiting user testing.** Use disposable project/file copies, keeping the original `.collie` safe. These actions have not been performed by the assistant. PL01/PL02 acceptance is also pending.

1. **Open Plan.** From the project root, launch with `npm run dev` using the repository’s supported Node/npm toolchain. Open a disposable project with existing notes, sources and saved chats, then switch from Write to Plan. Expect the same project and existing material; entering Plan sends no AI request.
2. **Drop files without accepting.** Drop supported chat JSON, notes TXT/Markdown or bibliography BIB/RIS files onto Plan, including over a chapter card. Expect the normal Import dialog and selected files. Choose categories and optionally instructions/model, then Submit. Expect the existing processing/result flow; no new material or chapter assignment exists before Accept. Cancel and reopen Import: expect retained unfinished selection/findings, with no automatic Submit or Accept. Unsupported files/directories should receive intake explanations rather than becoming manuscript text.
3. **Accept into the pool.** Accept the import. Expect the short imported-result notice and Plan’s Unplaced material pool with title/type/status filters reset. Newly accepted records are available there and through Research; use title search/pages if needed. The selected chapter has no automatic assignments, and Write has no inserted text. Existing import duplicate/omission reporting remains applicable.
4. **Collect through the existing editors.** Choose Add note, name/edit it, then return to Plan; expect one note in the pool. Choose Paste as note, paste prose and Add material; expect one editable note containing it. Also try normal paste while a board card/button has focus: expect the same note path. Paste into a title/text field: expect ordinary field editing. Back/return navigation must not create another record from an already consumed intent.
5. **Capture a URL/source.** Paste a single HTTP(S) URL through Paste as note. Expect the Sources form with URL filled and a message that the page has not been fetched. Enter a title/details and save; expect one source without automatic verification or fetched page content. Repeat with Add source: expect the same retained form with no preselected chapter links. Return to Plan and find each saved source.
6. **Keep distinct chat passages.** Open a saved native chat, select prose within one message and choose Keep passage (or its message-menu action). Expect a saved-passage notice with Open note and Open in Plan. Repeat in a long imported chat, using earlier/later transcript navigation to reach messages beyond its initial page/AI recall window. Keep two different passages from that chat, including a selection well into a long message after its remaining text loads. Expect separate notes with their own exact text; no AI request is needed. Selection is bounded to 20,000 canonical characters within one message; generated badges/media and cross-message selections are not passage text.
7. **Edit, assign and revisit.** Open a kept note, edit its title/body and save. Expect “Kept chat passage,” plus the unchanged original quote, chat title and author under its origin disclosure. Open original exchange: expect the correct message/passage position, including the user bubble for a user passage. Back to Plan preserves ordinary board selection/scroll. Open each of the two passages in Plan, choose different chapters in Add to and add them. Expect each chapter’s material to show its own note. Show all material exits the focused result. If an unconfirmed capture occurs naturally, Retry passage save should settle the same action without a second note; a definite stale refusal asks for a new selection.
8. **Use an exact source excerpt.** Open an existing retained excerpt in the source inspector (an earlier original version is useful too), then choose Use excerpt. Expect that existing excerpt selected in Plan. Choose a chapter under Add to and add it. Open original from the board or Write’s Chapter material: expect the same quote/source/version/page context. No citation is inserted and source verification remains unchanged.
9. **Save, reopen and copy offline.** Save the disposable `.collie` explicitly. Close/reopen it, then open a separate disposable independent copy using the existing copy/open workflow. Disconnect networking for this part. Expect notes, edited bodies, immutable passage quotes/original navigation, source excerpts and chapter assignments to remain available locally. Write and its existing text/Undo behavior should remain intact during ordinary Plan/Research switches. Save remains separate from local draft protection.
10. **Keyboard, narrow window and read-only access.** Repeat collection/assignment using labeled buttons, keyboard selection and the message menu (Shift+F10/context-menu key), then use a narrow window’s Material/Structure/Details panes. Expect reachable actions and visible focus. Where read-only access is available through the existing app, expect inspection/original access to remain available while creation, passage capture, import mutation and assignment are unavailable.

Please report the step, visible result and any message. Migration, native file drop, exact selection positioning, offline portability and accessibility remain unverified until these user results are supplied. PL04–PL06 are outside this stage.
