# CD05 manual guide

**CD05 is engineering partial.** The independent conversation integration is implemented — awaiting user testing. CD03's tool/content-log protections remain unfinished, so **Send reviewed request remains unavailable**, even after successful sign-in and model selection. A real response is not an expected result of this guide. No assistant tests, checks or launches were performed.

As a user:

1. Using the repository's existing Node **24.21.0** / npm **11.19.0** setup and installed dependencies, I run `npm run dev` myself. I open an **editable disposable project**, open the writing companion's **Conversations** view, and create a conversation. Writing and local history work without connecting Codex.
2. I type a short prompt, leave writing context and prior-message selection empty, and choose **Review request**. The review shows my exact prompt, zero attached writing/history and the current account/model or their absence. **Save request locally** remains usable; **Send reviewed request** is disabled with the actual availability explanation.
3. I choose **Save request locally** once or twice in quick succession. One **Not sent** request appears, with no assistant response and no promise of automatic later delivery. The notice distinguishes local working-project protection from project Save to the chosen file. I use project **Save** normally if I want to update that file.
4. I save another short local request, then select specific earlier message checkboxes for a new follow-up, including older pages if present. Review includes only my new prompt and selected messages in transcript order; its excluded count accounts for the rest. **Clear previous-message selection** removes those messages from the next review.
5. In the disposable manuscript, I select a short passage, use **Use selected passage**, and review. The exact protected text appears. I edit that writing before saving the reviewed request; stale revision refusal keeps my draft and asks me to capture/review again. **Use current section** captures its saved text instead. Removing context returns to no attached writing. Chat saving does not replace manuscript text or reset the editor.
6. Optionally, from the conversation's **Connect Codex…** or **Open connection settings**, I use **Continue with ChatGPT**, or explicitly **Resume Codex connection** for my saved account. These are real account actions; normal subscription/account-credit settings apply. In **Choose model and view availability**, I explicitly **Refresh models** and select a reported model. Settings and the conversation show the same selection. Missing/empty/failed catalogs remain explained; no model is invented. The unfinished tool/content-log protections still prevent Send. See the [CD02](codex-CD02.md) and [CD03](codex-CD03.md) guides for account details.
7. With a local review open, I choose another reported model, refresh the catalog, or change/resume the connection through those ordinary controls. The old review approval is cleared; my prompt, selected source and history remain. I review again before saving. **Check connection status** alone leaves a review intact when the connection/model has not changed. Switching to Research or hiding/reopening the companion preserves an unsent draft and transcript position.
8. If my disposable section or selected history exceeds the supported limits, I attempt review. Collie asks for a shorter prompt, smaller passage or fewer messages and keeps the draft without trimming or saving a partial request. The prompt limit is 16,000 characters, attached text 64,000, and the whole structured request including instructions 80,000. Ordinary text with many line breaks or quotes also counts its encoded size. I use my own disposable text; no script or injected data is needed.
9. After saving or explicitly clearing unsent drafts, I archive and restore the conversation, export its transcript to a **new filename**, then close normally and reopen with `npm run dev`. Saved local messages remain readable without Resume or resending. The optional reviewed-context appendix appears only when selected. Exporting to an existing filename keeps the old file and reports the conflict. On an already read-only disposable project, history/export stay available while new requests and edits remain disabled.
10. If an ordinary local action reports an uncertain acknowledgment, I keep Collie open and use **Retry the same local action**. If output protection is reported, I use the global work notice and the owning **Retry local protection** action. These recover the same work without starting another provider request. I do not induce failures, alter journals/credentials or fabricate responses. Existing real partial/failed/unknown records, if any, remain readable; **Use prompt in a new request** copies only the prompt and requires fresh context/review.

Report the step and visible outcome without credentials, raw provider logs or private writing. Live Send, streaming, Stop and retained real-response acceptance remain blocked by CD03 and unobserved. Stop here; CD06 is not part of this handoff.
