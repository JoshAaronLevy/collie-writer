# Pending user-owned editor/export fidelity scenarios

**Not executable through the current Stage 3 shell.** These are acceptance criteria for the real Stage 8, 15, 16 and 17 product paths. They are not a request to generate a corpus, run scripts or add temporary controls. The assistant has not created manuscripts, outputs or test code. Use writing you create yourself or licensed public material in disposable projects, and choose new output filenames. Save copies before data-risk actions.

1. Once the writing screen exists, enter headings 1–3, paragraphs, every supported text mark, safe links, line/page breaks, one-level lists and a block quotation. After reopening the disposable project, the content, formatting and structure should remain intact.
2. Enter accented Latin, combining characters, Greek/Cyrillic, Chinese/Japanese/Korean with an IME, and short Arabic/Hebrew quotations. Composition and undo/redo should preserve characters and selection; missing glyphs or layout differences should be reported. Full RTL manuscript layout is outside the selected scope.
3. Copy a passage containing a citation and author note through the eventual managed clipboard path, then move its section and undo/redo. Copies should have independent note bodies and moves should retain their references; editing the copied note should not edit the original. Current adapter rich-paste refusal should become a clear issue, never a silent loss of content.
4. Add managed PNG/JPEG images with alt text/captions and a plain rectangular table with a header row. In DOCX/PDF, images should fit without stretching or clipping; captions, rows and repeated headers should remain readable across page boundaries. Unsupported spans/nested content should be reported before export.
5. Once citation controls exist, use both pinned APA 7 and Chicago 18 styles with a book, chapter, article, report, thesis and webpage. Include repeated works, per-item locators/prefixes/suffixes, multi-item clusters and two works by the same author/year. Compare the output to an independently checked reference: earlier citations and bibliography should update consistently after disambiguation or reordering.
6. Mix author notes, Chicago prose citations and a citation inside an author note. Both outputs should use one sequence of real notes; the citation inside a note must not create a nested note. Switching to APA should retain the author's notes and move ordinary prose citations into author-date form.
7. Place a short note, several notes and a note longer than one page near successive page bottoms. Compare every note's beginning, middle and ending against the manuscript in Word/LibreOffice and a PDF reader. All content must survive, with readable continuation and matching calls; clipped/missing lines or endnote substitution fail D5.
8. With an existing disposable manuscript of roughly 300 pages, export Letter and A4 variants containing long tables, large images/captions and notes across section/page boundaries. Inspect the beginning, middle and end, note continuations and table splits. There should be no missing writing, duplicate passages, blank runaway pages or broken numbering. Record your platform, app artifact, reader versions and elapsed time; no performance result exists yet.
9. Disconnect from the internet before compiling the same project to DOCX and PDF. Both should complete with local styles/fonts/assets; a clean machine should not need old caches. Open DOCX in Word and LibreOffice where available, and PDF in a native reader. Regular/emphasized glyphs, embedded fonts, true notes and editable Word structures should remain usable; exact pagination across readers is not promised.
10. Once export jobs/destinations exist, edit after an export captures its revision and cancel a separate overwrite attempt. The completed output should name the captured revision, later edits should remain distinct, and cancellation should preserve the previous destination. Missing sources/assets or unsupported content should block loss rather than produce an apparently complete document.

Record results in `docs/validation/stage-03.md` only when supplied by the user. DOCX/IME findings gate D3/Stage 8 or 16 acceptance; citation findings gate D4/Stage 15; pagination/font findings gate D5/Stage 17 and release. A Paged.js failure triggers the correction/fallback procedure in [D5](../decisions/D5-local-pdf-pagination.md).
