# IH05 user walkthrough

**Implementation complete — awaiting user testing.** Required source-check outcomes are recorded separately in [the IH05 record](../validation/import-IH05.md). Use disposable projects/copies. No app launch, sample import or provider request was performed by the assistant.

1. **Prepare the app yourself and check local copying.** Relaunch your usual development application (`npm run dev` with the pinned toolchain) or your normal locally rebuilt application. Open/create a disposable project. Import a known structured conversation export with only AI conversations selected and blank instructions. Expect the compact summary and “Processed locally; no ChatGPT requests,” even without ChatGPT connected. After Accept, compare early/late original messages, roles, ordering and grouping in the ordinary AI pane. Separately import structured CSL-JSON/BibTeX/RIS with Sources and blank instructions; those source fields should remain local.
2. **Import prose references.** In another disposable selection, add real text/Markdown containing explicit bibliography references and select Sources; or use a supported conversation export with inline references as well as structured reference metadata. Choose an available model and Submit. Expect “Interpreting selected content,” completed-request progress and receiving/waiting activity, followed by the usual short summary. Structured metadata alone should not require recognition, and its presence must not hide additional reference-like prose. Counts/accuracy depend on the input and model; report omissions.
3. **Inspect literal results and origins.** Accept usable findings. Expect sources in Research with only supplied bibliographic facts, unverified status and original locations; sources extracted from message prose should retain their conversation/message origin. If that conversation was also imported, follow the original message link. For source-only imports, expect origin context without newly created chats. For selected Notes, inspect literal notes from supported note records or recognizable message note passages: no generated summary or invented authorship should replace the original wording.
4. **Apply a small, recognizable selection instruction.** Use a supported small export containing an obvious subset to exclude, such as a named conversation, note or source. Add an instruction asking to omit that subset, select the relevant categories/model and Submit. Expect interpretation using complete admitted context, then counts reflecting only the supported selection, or an explicit unresolved explanation. Accept and compare unchanged original bodies and the omitted subset; you should never need per-message decisions.
5. **Observe an honest instruction limitation.** On a disposable selection, request rewriting/summarizing instead of original-content selection, or use instructions with an export too large to fit complete context. Expect a limitation/unresolved result, with originals/instructions retained and no unfiltered candidates claiming that instruction was honored. The context limit is 50,000 packet characters including metadata and at most 128 destination candidates; narrowing files/export or removing instructions is the offered path. Unknown JSON plus instructions can also be explicitly limited. No automatic repair or whole-file AI fallback should begin.
6. **Reuse and interrupt.** At a healthy summary, Cancel and Submit unchanged. Expect saved findings/summary without new ChatGPT requests. During ordinary interpretation, Cancel; expect scheduling to stop and setup/completed responses to remain. If unread passages remain, explicitly Continue when ready; completed passages must not be sent again. A naturally larger selection can pause after at most 32 interpretation requests for another explicit Continue. Check status/protection recovery must not resend. Invalid/failed responses remain retained; general reanalysis and confirmed quota retry are not implemented in IH05. Do not deliberately exhaust usage or inject failures.
7. **Save and reopen.** Save the disposable project after accepting interpreted findings, close/reopen it and inspect ordinary conversations/sources/notes and origins. Save/reopen an unfinished selection too: expect retained setup/findings, with explicit Submit/Continue required before inference. A stopped import is not accepted merely by Save. Report Save/migration/copy/reopen failures; code checks did not exercise native persistence.
8. **Check the simple layout.** At a narrow window or 200% zoom, navigate setup/processing/results by keyboard. Expect the stable header/footer, reachable Cancel/Accept, actual progress announcements and disabled Re-Analyze placeholder, without payload inspection, mapping choices or a message dashboard.

If a suitable prose example or natural interruption is unavailable, leave that observation pending. Please report the model, categories, instructions, visible request count and exact limitation for any mismatch. IH06/IH07 require separate requests.
