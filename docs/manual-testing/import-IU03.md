# IU03 user guide

**Implementation complete — awaiting user testing.** This stage completes the ordinary two-view import path. Use a disposable project copy and a small supported file set that you are comfortable sending to your connected ChatGPT account. No runtime testing has been performed by the assistant.

Stage IU03 complete. As a user:

1. Launch the updated development app with `npm run dev`, open the disposable project and open Import. Choose files, select AI conversations and Sources, optionally add instructions, choose an available model and Submit. Expect compact processing, then Ready to import automatically, with no preview, consent checkbox, part controls or individual message choices.
2. Read the summary. Expect the number of prepared conversations, their titles and message counts, and total sources, including a compact already-in-Research suffix when applicable. Only selected categories appear. Re-Analyze should be disabled with Coming later and should do nothing. If your normal file contains more than 50 conversations, scroll the single body; further titles should appear and totals should describe the whole result. Footer actions should remain reachable in a narrow window or at 200% zoom.
3. Click Cancel in results. Expect the populated setup with files/categories/instructions/model retained and no accepted content. Submit unchanged; expect the same summary without another ChatGPT analysis. Close/Escape in idle results should also return to setup, rather than discard findings.
4. Click Accept once. Expect Importing while the write is pending, then the dialog to close and a short success notice. There should be no third report screen or automatic navigation. Open the ordinary AI conversation pane, Research and Notes as applicable; expect the displayed findings and supported source-to-conversation/message links, with your manuscript and unrelated drafts preserved.
5. Save the disposable project using the normal project Save action, close and reopen it. Expect accepted content/origins to remain available and no analysis to start on opening. Reopen Import; the completed import should not appear as a selectable inventory. With no other unfinished import, expect a fresh setup form.
6. In another disposable selection, choose Sources only or Notes only with suitable files. Expect only that category in results and only its destinations after Accept. Source-only origins should remain traceable without creating unchecked chats. If the importer produces an empty or wholly already-present result, expect a short explanation, disabled Accept and no success notice. Do not change or manufacture files merely to trigger that state.
7. If you naturally edit the project after obtaining results, return to setup, close Import, make the edit, reopen and Submit unchanged. Expect local summary refresh rather than another AI analysis. If a change makes the summary stale at acceptance, expect an updated summary and another required Accept, with no content added by the first click. For a naturally uncertain write, expect Check status; dismissal/reopening must retain it, and status checks must not analyze or duplicate the import. Do not inject failures.

Report missing items, incorrect counts/origins, confusing copy, inaccessible actions or unexpected analysis. Full app-restart/older unfinished-import adaptation, final supporting-code cleanup and integrated polish remain IU04–IU05. Stop here pending observations or an explicit next-stage request.
