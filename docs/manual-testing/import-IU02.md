# IU02 user guide

**Implementation complete — awaiting user testing.** IU02 implements the compact setup and one-Submit analysis. It saves prepared findings but does not yet show the summary/Accept modal; IU03 adds that. Do not complete this stage through the old per-message review dashboard. Use files you are comfortable sending to your connected ChatGPT account.

Stage IU02 complete. As a user:

1. Launch the updated development app with the repository's normal `npm run dev` command and open a disposable copy of a project. Open Import. Expect a compact modal with the project name, Files, AI conversations/Sources/Notes, optional instructions, Model, Cancel and Submit. There should be no saved-selection inventory, local-preview buttons, request ceilings or payload/part list.
2. Add a small supported file or file set. Remove one filename, then add it again using Add files. Expect only selected filenames to appear, with file sizes and remove controls; re-adding a retained original selects it again. Choose categories and optionally enter instructions. Cancel and reopen Import; expect the same populated form without analysis starting.
3. If disconnected, use Connect ChatGPT, finish the existing account dialog and reopen Import. Expect the form to remain populated. Choose another available catalog model, if offered; the dropdown should show the saved selection without starting analysis. Submit should be unavailable while the connection/model needs attention or no files/categories are selected.
4. With a small readable selection and a ready model, click Submit once. Expect in-place Preparing files, Analyzing with ChatGPT and Preparing your import states without another consent, review or per-message step. On a successful run, expect “Analysis complete. Your findings are saved.” No conversations, sources or notes should be added yet. Cancel to close, reopen and Submit unchanged; expect the saved-findings state without another analysis.
5. Change the input, Submit and click Cancel during preparation/analysis. Expect Stopping when necessary, then the populated form; no further requests should be dispatched once cancellation takes effect. Already received work remains protected and the request may still finish saving. Reopening alone must not restart it. A later explicit Submit may process eligible unsent work; failed/unknown work must first be settled and is never silently retried.
6. Use keyboard navigation and a narrow window or 200% zoom. Expect labeled fields/remove buttons and reachable Cancel/Submit in a stable footer, with one scrolling setup body. Enter in instructions should enter text rather than send the form. Report any focus, wrapping or layout issue.

If a real failure occurs, expect a short reason and retained choices. Check status reads/reconciles saved work; Try saving again, when shown, retries local saving only. For a retained failed outcome requiring dismissal, close Import and use the existing AI work notice. Do not manufacture failures. Report the visible message and whether the form was preserved; do not judge the final two-modal import until IU03 is implemented. Stop here pending observations or an explicit next-stage request.
