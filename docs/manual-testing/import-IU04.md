# IU04 user guide

**Implementation complete — awaiting user testing.** These steps belong to Josh; no assistant runtime testing was performed. Use disposable project copies and real existing files. Launch the updated app using your normal local workflow. Do not manufacture failures or run automated suites for this guide.

1. Open a disposable copy of an older unfinished import and click Import. Expect the populated files/categories/instructions, the normal model dropdown and either the saved short summary or contextual recovery actions. No analysis should start merely from opening, and no batch-ID selector or technical dashboard should appear.
2. If protected findings are available, click View available results. Expect the same simple conversation/message counts and selected-category totals, with Cancel, disabled Re-Analyze and Accept. For a valid older single-request result, this should prepare locally without another ChatGPT request. Older saved corrections/exclusions should remain reflected in the result. If old findings cannot produce a usable summary, expect a short error and preserved data rather than invented content or an automatic resend.
3. Cancel from results, then close the populated form. Save the disposable project normally, close it and reopen it. Click Import again. Expect the retained selection/findings to return without analysis or acceptance. Returning to the summary should not require per-message choices.
4. During a normal new analysis, click Cancel once. Expect Stopping followed by a settled form and preserved received findings. If usable results exist, View available results should show them. If Continue analysis is offered, click it only if you want to send the unsent work; expect an explicit continuation and no replay of failed/already-attempted requests. If a partial summary has been canceled back to setup, Continue analysis should remain available for unsent work there.
5. If a canceled/failed outcome naturally needs attention, use Check status and the contextual Finish recovery or Try saving again action shown. Expect local recovery with received content retained and no new ChatGPT request. When Start new import is offered, click it on the disposable project: expect a fresh form, with the old selection retired rather than its originals/history deleted. Cancel/close alone should retain findings.
6. Accept a usable summary once, then inspect ordinary Chats, Research and Notes. Expect one import, the original messages and supported origin relationships, with no extra report screen or forced navigation. Save and reopen the disposable project. Expect accepted content to persist and no automatic analysis. With no other unfinished selection, Import should start with a fresh form.
7. If you already have an independent disposable project copy, open it and click Import. Expect its retained data/recovery presentation, with no copied execution grant and no automatic acceptance. If an uncertain acceptance reply occurs naturally, Check status should resolve that exact import or keep it pending; it must not duplicate accepted content or start inference. Report access/account/recovery issues only if naturally encountered.

Report missing findings, changed old corrections/exclusions, unexpected requests, duplicate content, lost relationships or confusing/inaccessible controls. Full integrated visual/accessibility polish and final acceptance handoff remain IU05. Stage progression does not establish runtime acceptance.
