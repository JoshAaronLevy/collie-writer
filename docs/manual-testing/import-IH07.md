# IH07 integrated hybrid import — user guide

October 11, 2026 — **implementation complete — awaiting user testing**. Run these actions yourself in disposable projects/copies, using real files you already own. Launch/relaunch Collie with your usual workflow (`npm run dev` for this checkout if applicable). Do not deliberately exhaust usage, damage files, interrupt writes or manufacture failures. Earlier stages and clean code checks do not establish acceptance.

1. **Real large JSON and acceptance.** In an already-created disposable project, open Import, add `/Users/joshlevy/Desktop/Cultural Analysis App/api/data/conversations/cultural-analysis/cultural-analysis.conversation.json`, select AI conversations and Sources, leave instructions blank and Submit. Expect local reading/extraction of supported records with no per-message decisions or manual file splitting. If additional inline references need interpretation, expect targeted content activity using your selected model, not AI copying the whole transcript. The compact summary shows conversation titles/message totals and source total. Only Accept adds findings and closes. Inspect early/late messages, roles/order and source conversation/message origins in the ordinary panes. No fixed counts or guaranteed extraction quality are asserted.
2. **Observe a fully local/disconnected path.** In another disposable project, select AI conversations only for a recognized export, or Sources only for a supported bibliography, or Notes only for a literal note input; use blank instructions while ChatGPT is disconnected. Expect Submit to remain available and a useful summary saying “Processed locally; no ChatGPT requests.” The model is unnecessary here. Cancel returns to the populated form; unchanged Submit returns to the same findings. Accept adds only selected categories. If the file needs mapping/interpretation, expect a clear connection/model reason and preserved setup instead of a claim that no content exists. Returning from account management alone must not send.
3. **Unfamiliar JSON and mixed files.** Connect your own account and choose a model. Import a real unfamiliar but regular JSON export, optionally with a known export. Expect Understanding file structure, a structure-task bar and request attempts for this run, then extraction in TypeScript across the admitted file. Necessary prose may start a separate content-task phase. Inspect records beyond the sampled beginning/end, grouping, original bodies and source links after Accept. Independent supported findings survive an unusable mapping; omissions are explicit. Cancel from a healthy summary keeps setup simple, without routine recovery buttons or payload screens.
4. **Prose, Notes and instructions.** Import suitable real Markdown/prose with Sources and/or Notes, or apply a meaningful inclusion/exclusion instruction to supported structured content. Expect bounded content-task progress and literal original spans/relationships in accepted findings. Instructions are honored or receive a clear limitation; oversized/unsupported context cannot silently include everything. Generated rewrites are not imported original notes or messages. Incomplete source metadata stays incomplete and unverified. Re-Analyze stays disabled, with “Coming later.”
5. **Duplicates and originals.** Save an accepted disposable project, then start another import using the same accepted original/categories. Expect already-present/skip behavior rather than duplicate conversations/messages or overwritten source metadata. Strong source identifiers may reuse an existing source and retain multiple origins. Deselect/remove a file from setup: it stops being selected, while previously retained original/history remains project-owned. Save preserves findings and originals; saving a prepared import alone never adds content to the ordinary panes.
6. **Ordinary cancellation, partial findings and reopening.** During mapping/interpretation, Cancel once, wait for stopping/recovery, then Save and reopen the disposable project normally. Expect no automatic send or acceptance. Reopen Import and Check status if offered; resolve actual protection/outcome recovery through its existing action. View available results prepares only usable findings locally, without new inference. A partial summary says Accept finishes this selection; to resume later, Cancel back to setup and explicitly Continue analysis. Continue processes unread or eligible confirmed-refused tasks and reuses successful results. After partial Accept, omitted material requires a new import.
7. **Naturally encountered limits only.** If ChatGPT reports a real plan/app usage limit, expect a clear pause, retained findings and Manage usage. Generic request limiting should be described separately; a provider minimum retry time is respected when supplied. After availability returns, explicitly Continue: confirmed refused work gets a fresh bounded attempt, successful tasks are reused, and no automatic retry loop runs. At most three attempts per task and 8 mapping/32 content requests per explicit run apply. Unknown transport, invalid output or unprotected responses need their stated recovery; they are not blindly retried. If no limit occurs, leave this case unverified.
8. **Legacy and portable copies.** Open disposable copies of older accepted and unfinished import projects. Expect accepted transcripts, sources, notes, origins and receipts to remain readable. Existing ready findings can still be accepted; exact pending output/commit recovery takes priority. After settled unfinished work, Use new importer uses retained files/settings without picking them again. It creates a fresh summary; earlier manual choices stay historical and are not silently applied. Save/Duplicate and reopen a disposable copy: content/evidence remains, but no live request authority is inherited.
9. **Layout, keyboard and activity.** At narrow width and 200% zoom, Tab/Shift+Tab and scroll through setup/results. Expect wrapped names/buttons, a bounded scrolling body and reachable stable header/footer. Escape/close follows the same Cancel behavior; during stopping or atomic import, dismissal stays guarded. A disappearing/disabled import control hands focus to the new presentation without stealing newer focus. With reduced motion enabled, the spinner/fade stops; labels and progress remain. Screen reader announcements describe phase/settled task counts, not every streamed character or second. Long conversation summaries remain scrollable.
