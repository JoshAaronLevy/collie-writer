# AC07 manual guide — chat references to Research and writing

**Implementation complete — awaiting user testing.** The [AC08 integrated guide](ai-conversations-AC08.md) supersedes the plain-text selection limitation below and is the current complete walkthrough. These are user actions and expected outcomes, not observed results. Use a disposable copy of a project. Preserve the original saved project and local recovery. Close Collie normally, stop the old development process, then run `npm run dev` yourself; this stage changes the main/worker contract and project schema, so renderer hot reload is insufficient.

1. Open a project with a completed research answer. Beside an unsaved provider reference, choose **Add to Research**. A compact **Save reference** dialog pre-fills the title and URL. Author/date remain empty unless you enter them, and verification starts unchecked. Saving a retained reference needs no new ChatGPT request.
2. Edit a title or optional detail, then close the dialog or choose **Keep for later**. Open the chat's three-dot menu → **Resume reference review**. Your fields remain. Selecting a different reference while this draft exists reopens the retained draft instead of discarding it. **Discard review** explicitly abandons it; an unresolved save cannot be discarded.
3. Choose **Continue**, review matches, then **Add to Research**. The dialog confirms the save and offers **Cite in writing**, **Open source** and **Done**. The answer now shows **In Research**, **Open source** and **Cite**. Research contains an ordinary source; no original file or verified excerpt has been created.
4. In an ordinary completed answer, select a short plain-text book title (within any formatting, rather than across Markdown boundaries). **Save reference** appears beneath the answer. Choose it, correct the title/type and enter known author/date/publisher/ISBN details as desired. Continue and save. The book appears in Research and in the answer's Project references disclosure. Unknown fields stay empty.
5. Select that same title again and continue with the same metadata, or review another reference whose URL/DOI/ISBN matches an existing source. Choose **Use existing**. The existing source remains one record with its previous metadata and verification state; its chat provenance gains the new link. A distinct record is created only if you explicitly choose **Save as a separate source**.
6. Place the caret at the desired point in an editable manuscript item, then choose **Cite** beside a saved chat reference. The existing citation dialog opens with that exact source selected. Add a locator if appropriate and choose **Apply citation**. A real citation is inserted at the captured position. Cancel inserts nothing. Existing dirty source forms, manuscript text and undo history remain intact.
7. If you naturally change focus, the manuscript item or writing while a citation handoff is loading, it must refuse a stale target. Select the intended position and choose Cite again. Removed sources offer their Research link rather than Cite. Do not manufacture failures or modify local databases for this check.
8. Open the source → **Usage and context** → **Saved from conversations**. See the original URL/selected text, save time and historical verification choice, with **Open conversation**. Archive the original chat. Its source, provenance and manuscript citation remain; reopening the archived chat does not start inference.
9. Save the disposable project, close, fully reopen and inspect its chat, Research and writing. All committed sources, provenance and citations remain. Use the existing project-copy/open-as-copy workflow to check the same relationships under a new project identity. Unsubmitted reference reviews must be saved or explicitly discarded before closing; they are not portable saved sources.
10. Export the manuscript with its existing bibliography settings and export the chat transcript. The manuscript uses the normal citation/bibliography pipeline; the transcript includes saved-reference provenance. Bibliography-only export retains ordinary metadata and declares omitted project provenance. Missing metadata/originals remain visible through existing Research/citation controls.
11. Only if a save naturally reports uncertainty, use **Retry this save**. It keeps the original fields and operation and resolves to one source/receipt. If a candidate changes before saving, review matches again without losing edits. Report the actual outcome; these error paths remain unobserved otherwise.

Also check keyboard selection/activation, Escape/close/resume, narrow panes, zoom, input composition and screen-reader dialog names/focus return. Runtime/native persistence, duplicate quality, provider research and export appearance remain pending until you report results. AC08 is not included.
