# IH04 user walkthrough

Implementation complete — awaiting user testing. Format/lint/typecheck outcomes are recorded separately in [the IH04 record](../validation/import-IH04.md). Use disposable projects/copies. The assistant has not launched the app, imported a sample or sent a provider request.

1. **Prepare the app yourself.** Relaunch your usual development application using the repository's normal development command (`npm run dev` with the pinned toolchain), or your normal locally rebuilt application workflow. Open/create a disposable destination project. Import your known conversation JSON with Conversations/Sources and blank instructions. Expect the normal summary and “Processed locally; no ChatGPT requests,” even without a connection. A stored model preference does not block this local route.
2. **Discover an unfamiliar real JSON export.** Start a new import and add a real structured export with unfamiliar field names/nesting that the known reader does not already support. Leave instructions blank, choose your available ChatGPT model, then Submit. Expect “Understanding file structure,” a bounded structure-request count and receiving/waiting activity, then local extraction and the usual compact summary. If the structure or model response cannot be mapped safely, expect a specific omission/failure and retained originals, rather than a claim that all content was successfully read. No mapping editor or individual message choices should appear.
3. **Inspect the whole result after Accept.** When the summary has usable findings, Accept. Expect the modal to close and imported content in ordinary AI conversations, Research and/or Notes. Compare early and late messages with the original, including bodies, conversation grouping/order, original metadata and source/message origins. Notes should retain literal text and supported labels/authorship. Sources must not acquire invented or verified facts. Report missing/incorrect content; no fixed counts or model accuracy are asserted.
4. **Mix and reuse.** In another disposable import, combine a known export with an unfamiliar JSON. Expect only unfamiliar structure work to use ChatGPT. At the summary choose Cancel, then Submit unchanged. Expect saved findings/summary to be reused without another AI request. Accepting a repeated original in a new selection should use existing duplicate handling, without overwriting accepted content.
5. **Observe interruption and connection handling.** During ordinary discovery, Cancel. Expect scheduling to stop and completed findings/setup to remain. If unread groups remain, explicitly Continue when the connection is ready; successful groups should not be sent again. If a response fails or needs protection naturally, use Check status / the existing contextual recovery action. These actions must not silently resend. A disconnected unfamiliar import should keep files and explain why ChatGPT is required; Manage ChatGPT alone must not start it. Do not deliberately exhaust usage or inject failures. Retrying a confirmed quota-refused group belongs to IH06 and remains unavailable in IH04.
6. **Save and reopen.** Save the disposable project after accepted work, close and reopen it; inspect the imported conversations and origins. Also Save/reopen an unfinished disposable selection. Expect retained originals/findings and no automatic request on opening. Explicit Submit/Continue remains necessary. Use a disposable older project copy to inspect retained legacy content/recovery. Report any Save, migration, re-open or copy failure; required code checks did not exercise these operations.
7. **Keep the simple layout.** At a narrow window or 200% zoom, use keyboard navigation through setup, processing and results. Expect the stable header/footer, accessible progress/status, reachable Cancel/Accept and disabled Re-Analyze placeholder. Nonblank instructions must remain visible and explicitly limited until IH05, with no unfiltered import claiming to honor them.

If no unfamiliar export or naturally interrupted request is available, record those observations as pending. Please report the chosen model, requested categories, visible request count and any exact error/omission. No subsequent stage is inferred from this walkthrough.
