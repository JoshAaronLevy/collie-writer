2. If signed out, use **Continue with ChatGPT** and complete browser authorization. If already connected, use **Try again** under Model. Expected: “Setting up ChatGPT…” appears; supported models load and a model is selected without a separate refresh-and-pick sequence. The dot becomes green when the account is ready and no known account/usage issue remains. A provider refusal remains visible rather than being called success.
3. If more than one model is available, select a different **Model for this account**, then choose **Refresh models**. Expected: your choice remains selected if still available. No AI response or new conversation is created by either action.
4. Close Collie normally, reopen with `npm run dev`, open ChatGPT, and choose **Try again**. Expected: a fresh catalog restores your valid model choice. Needing this explicit preparation after restart is the UI02 boundary; launch preparation belongs to UI04.

Expected: the input remains present and the request requires review again before Send. Do not send unless you want to exercise your account's normal usage policy.
7. If a network interruption or expired session occurs naturally during setup, read its status. Expected: the account/registration is retained, progress settles into an actionable problem, and no repeated automatic attempt begins. Use **Try again** once when service is available. 8. If a remembered model naturally disappears or is refused, refresh the catalog. Expected: it stays unselected/yellow and asks for a replacement; Collie does not silently choose another model. Expected: the panel offers **Retry saving model choice**, or **Retry reading model choices** for unreadable saved preferences. Saving retries only the retained local choice; it does not repeat sign-in or inference. A still-unreadable record remains an actionable problem and the saved account stays present. Do not delete or edit encrypted storage as part of this guide.
10. If you close or suspend during setup, follow the existing active-work close choices. Expected: Keep open retains the session; confirmed stop/close or suspension settles/cancels provider work without silently replaying it on resume. Ordinary writing protection still applies. A failed local write must be protected before close can succeed.
11. Navigate away from and back to Settings, switch projects, and leave the app idle through several status updates. Expected: this does not restart setup or change the chosen model. Use Tab/Enter to operate the model and retry controls: labels and progress remain understandable and focus stays within the existing navigation flow.
