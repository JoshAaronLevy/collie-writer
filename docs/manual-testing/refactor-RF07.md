# RF07 — One straightforward export flow

**Implementation complete — awaiting user testing.** Use a disposable project/copy and a dedicated output folder, especially for replacement and cancellation. Format/lint/typecheck and source inspection do not establish native behavior or output fidelity.

Stage RF07 complete. As a user:

1. **Launch normally** (for development, run `npm run dev` with the pinned toolchain), open a disposable project with at least two active writing sections, edit its text, then open Export. Word (DOCX) is the initial format; the full active manuscript follows outline order. There are no numbered steps or mandatory preview/revision review. Choose a new destination through **Export…**: the latest writing is protected locally, then the native picker opens. The finished result has **Show file**, which reveals that file in Finder/Explorer, and **Done**, which returns to writing. Export does not mark the `.collie` project file as Saved.
2. **Repeat with PDF, Markdown and Plain text**, using new names. Every chosen format remains available in free/read-only access, one at a time. Open each output yourself: check section order, tables, images, citations, footnotes and bibliography against the writing. Markdown keeps image files in the adjacent folder; plain text discloses omitted image pixels/layout before export and lists actual losses afterward. PDF pagination/font/footnote fidelity remains a user acceptance gate.
3. **Cancel the native destination picker.** Export options stay available, without creating an export job or changing existing files. Export again with a fresh destination. If incomplete source details are naturally present in the disposable project, Export first shows a short omissions dialog: **Cancel** creates no output, **Review sources** opens Research, and **Export with omissions…** proceeds for those specific unchanged choices/writing. Correcting writing, source details, style or options requires a fresh preparation. A broken source reference, missing image or unsupported compilation still blocks export with its actual correction message; the omissions action cannot bypass it.
4. **Use the ordinary DOCX Export action to select an existing disposable DOCX.** Cancel the focused replacement confirmation: existing bytes remain. Repeat and choose **Replace inspected DOCX**: the new DOCX appears at the selected path, the previous DOCX remains beside it, and the result lists its retained location. Open both copies yourself. There is no separate replacement page/action. Existing PDF/Markdown/text outputs, and all batch collisions, remain kept/skipped with per-file explanations rather than silently replaced.
5. **Open Sections and order.** Omit a section, move selected sections under Custom order, export and inspect the resulting order. **Use full manuscript in outline order** restores the default; new active sections join that default automatically. Missing/inactive recipe sections remain visible and must be removed or replaced. Layout exposes Letter/A4, title-page and description-property choices; descriptions are not printed on title pages or added to Markdown/text.
6. **Use Saved recipes when available.** Existing recipes load stable sections/order/page size/formats and reset title-page/description choices. Free access exports one recipe format at a time; genuine paid access enables creating/updating recipes and selecting several formats for one folder export. An uncertain recipe Save keeps its choices locked and retries the same operation. Do not fabricate paid access to exercise this path.
7. **During an export long enough to observe, return to writing or another project**, then use its scoped **View export result** link. The matching job/result returns, with focus on that result when no newer focus/composition/dialog blocks it. A subsequent export keeps earlier results available. **Cancel export** stops remaining render work; completed files remain usable and pending formats report cancellation. During publication the app finishes the current file instead of offering unsafe cancellation. Navigating to results, Done or Show file never restarts export.
8. **Use the keyboard at narrow width/increased zoom.** Options, per-file results and long omissions lists scroll inside their bounded bodies; the primary footer actions remain reachable. The omissions dialog traps focus and returns it after Cancel; successful exports reach the results heading. On a naturally encountered disk/full, moved output or uncertain publication, keep retained files/reports, follow the specific message and inspect outputs before retrying. Do not inject failures to create these conditions.

Older DOCX-only job reports remain readable/cancellable through the existing status owner; no restart-persistent job browser was added. Native replacement, cancellation races, output fidelity, free/paid behavior and accessibility remain unverified until your observations. RF08 is not implemented by this stage.
