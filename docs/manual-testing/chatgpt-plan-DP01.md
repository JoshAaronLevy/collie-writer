Proofreading remains unavailable on this route. If discovery fails, use the failure-stage instructions below.
6. Return to your project’s **Write** workspace, open the **AI** writing companion, choose **Conversations**, and create a conversation titled **DP01 synthetic claim check**. This tests the transport and conversation workflow, not the full P06 feature or validated claim-checking quality.

Then quit normally, reopen with `npm run dev`, and open the same project/conversation. Expected: the request, actual answer, model and completed state remain readable without resending. Model choices start unloaded after restart; reading history requires no model refresh or fresh inference. You can also use **Conversation actions → Export transcript…** with a new filename to read the saved text independently.

## If a step fails

Read **ChatGPT plan connection** in Settings or in the conversation’s connection section. It separately shows identity, plan authorization, models and the latest request outcome. Capture the displayed failure stage, HTTP status, safe code/field, body shape and OpenAI request reference if present. Include the model and visible conversation outcome. Do not send credentials, callback URLs, ID-token hints or credential files. Detailed connection diagnostics are session-local; copy them before another account action or quitting. Saved history retains its bounded reason and actual output.

| Displayed stage                                           | What it establishes / next action                                                                                                                                                                                                                                         |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| App registration / Browser sign-in                        | No completed authorization yet. Report the browser’s visible refusal or whether the callback returned. If you closed the browser, Cancel sign-in; a later attempt uses fresh state/PKCE.                                                                                  |
| Authorization-code exchange / Account identity validation | The browser returned, but Collie could not establish a valid grant. Continue the retained registration; do not create or paste a client ID or token.                                                                                                                      |
| ChatGPT plan authorization                                | Identity can be valid while plan use is absent. Explicitly reauthorize the same saved account.                                                                                                                                                                            |
| Session renewal                                           | A known terminal refresh error requires browser reauthorization of the saved account. Temporary endpoint failures preserve credentials. A lost rotation result requires reauthorization rather than replaying an old refresh token.                                       |
| Account model discovery                                   | No approved model choice was established. Report the HTTP/code/shape; do not assume login proved inference access.                                                                                                                                                        |
| Request admission                                         | OpenAI refused the HTTP request before streaming. A 401 concerns accepted identity/permission, 403 concerns access/policy, and 503 may indicate temporary routing unavailability. Preserve the exact code rather than assuming commercial approval is the cause.          |
| Response stream                                           | Partial output is not success. Failed/incomplete/unknown outcomes stay saved; review the reported code. Usage-limit errors can arrive after text starts.                                                                                                                  |
| Protected credential storage / local output protection    | Keep the window open and use the applicable **Retry saving connection state** or **Retry local protection** control. If both need attention, protect the conversation output first, then retry the credential state. These retry local persistence only, never inference. |

`subscription_sharing_user_not_eligible` is an account/workspace/policy prerequisite reported by OpenAI. `subscription_sharing_usage_limit_exceeded` can be an app-specific or shared plan limit. Review [ChatGPT Settings → Usage](https://chatgpt.com/settings/usage); Collie will not buy credits or change settings. Direct authorization can follow existing account credit settings, so this is not an included-only spending guarantee. No failure causes API-key billing fallback. [Official recovery guidance](https://developers.openai.com/siwc/token-sharing-open-source/errors-and-recovery)

After a confirmed request refusal, the app clears the model selection to pause further sends. A later attempt requires explicit model refresh/selection, a new review and a new request. Reopening, checking status, recovering or protecting the old attempt cannot resend it.
