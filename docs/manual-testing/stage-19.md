# Stage 19 user-owned manual guide

Use your normal local launch workflow with disposable projects and separate disposable project-file copies. The assistant did not launch the app or run any checks. The sample is fictional product content. Do not reset your everyday local work.

Stage 19 complete. As a user:

1. When I open the Tutorial and create its sample, I should see an editable, clearly fictional project with a short cited draft and a retained text source. My free personal-project choice should remain independent.
2. When I follow the task path with keyboard navigation—template or sample, writing, Protect locally, first Save, source inspection/excerpt, question or claim, citation preview and export—I should be able to reach each step without dragging. Canceling the first Save should leave local recovery visible and no destination assigned.
3. When I back up a disposable edited sample and create a fresh sample, I should see the new sample while the previous sample, its edits and any selected file remain available as a separate local project. Personal projects should remain unchanged.
4. When I choose Show project file for a saved disposable project, my file manager should reveal that chosen file. Show local working and recovery folder should open the separate device-local folder; Locate moved file, Save As, Backup/Restore and recovery inspection should retain their distinct meanings.
5. When I use only keyboard input through the editor, native dialogs, source inspector, status messages, outline Up/Down or Move, and long search-result pages, focus should stay discoverable. Changing result pages should return focus to the result summary.
6. When I set 200% zoom, enable high contrast and reduced motion, and inspect the narrowest supported window, essential controls and writing should remain readable and reachable. With available VoiceOver or NVDA, headings, note/manuscript labels and status changes should make sense.
7. When I request a Support preview after working in a disposable project, it should show only versions, platform, storage state, uptime and known error codes. It should contain no writing, title, filename, path, URL, source quote, hash or credential, and should send nothing automatically.
8. When I use the app with network access blocked and inspect its controlled screens, I should still be able to write, inspect a retained source, search, cite, Save, back up and export. I should see no advertising, sponsored/affiliate material, automatic purchase/update connection or content upload. An external Help link should require an explicit confirmation.

If a native dialog, screen reader, clean-machine resource or file workflow differs, report the observed action, platform and result. Paid activation remains unavailable until authentic Stage 20 issuer configuration; Stage 18's writer-value decision also remains pending.
