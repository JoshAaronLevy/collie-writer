Pending operation links resolve the owning scope before opening it. Export result links additionally identify the session job. Runtime versions are intentionally in About/support, while actionable storage, save, access and recovery failures remain in global/contextual status. I09 introduces no new general-purpose filesystem or network interface.

**I11 addendum, October 2:** Connection UI is now implemented across the above entry points. Continue without AI retains the same project and can open for reading without changing free designation. Account completion does not automatically replace the current destination; guarded Return to connection and origin/visible-focus restoration preserve ongoing work. The [I11 guide](../manual-testing/improvement-I11.md) owns current and conditional later observations. No user acceptance is recorded.

## I12 conversation destination

Write → AI now opens the retained conversation foundation: title search and Active/Archived library, conversation transcript/composer, exact sharing review and Conversation actions → UTF-8 transcript export. Settings → AI connections still owns account management. No new permanent workspace destination/column was added. A shell notice returns to relevant unfinished conversation work; explicit reveal also opens the alternate companion pane on narrow windows. Ordinary panel/view changes retain the manuscript, conversation draft and scroll. Unsent input is protected by close/project/access guards and must be saved locally or explicitly cleared. Provider output is owned by main beyond view visibility. Context and transcript data are schema 11 portable content; account execution remains local. See [I12's decision](../decisions/improvement-12-conversation-foundation.md).
