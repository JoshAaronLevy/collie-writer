## I13 proofreading in the AI companion

Write → AI assistance selector → Proofreading opens the retained mechanics review. Choose Selected passage or Current section → inspect exact context/coverage → Save review locally or eligible explicit Run → open saved findings → Apply / Ignore / Undo ignore. Current I10 gates keep Run unavailable. Saved reviews page by 20 and finding lists by 10; global proofreading status returns to retained work. Switching to Conversations retains both owners and the manuscript. No new permanent column or routed workspace destination is added.

A current finding can select its exact original passage. Unknown Apply acknowledgments pause conflicting editing/navigation until Reconcile correction. Broader P modes, inline flags and chapter/book scopes remain separate.
